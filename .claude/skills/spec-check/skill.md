description: Reviews spec (features, plans, epics, stories, user-journey) for consistency and accuracy
---

**Instructions**

- Review plan, spec, and user-journey folders in docs/
- Ensure consistency across the documents given latest instructions e.g. change spec A or plan B and it deviates from
  the existing docs
- Ensure epics and stories have edge-cases, acceptance criteria, well-defined tasks with checkboxes, and tests
  (integration and unit)
- Ensure the docs are concise and use simple business language
- Do not add code samples
- Add representative wire-frames for clarity

**Actions**

- Find gaps
- Enter plan mode to summarize gaps and take actions
